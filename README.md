# GitOps Demo using Argo CD + Kubernetes

## 🚀 Project Overview
This project demonstrates GitOps using Argo CD.

## 🧰 Tools Used
- Kubernetes (Minikube)
- Argo CD
- GitHub

## 📦 Deployment
Apply using Argo CD or kubectl:

kubectl apply -f deployment.yaml
kubectl apply -f service.yaml

## 🔄 GitOps Flow
GitHub → Argo CD → Kubernetes
